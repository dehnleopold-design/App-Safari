# App-Safari

Fake-Safari als Web-App (Prank). Egal welche Adresse eingegeben wird – es erscheint immer dasselbe Bild.

## Bedienung
- **Adresszeile antippen** → beliebigen Text eingeben → „Öffnen“/Enter. Der Text wird als Domain angezeigt (`https://`, `www.` und Pfad werden entfernt).
- **Geheimes Menü:** 3× schnell auf das **Tabs-Symbol** oben rechts tippen (iPad) bzw. auf **„…“** unten rechts (iPhone).
  - Bild auswählen (wird auf dem Gerät gespeichert)
  - Darstellung: volle Breite & scrollbar / Bildschirm füllen / ganz sichtbar
  - Ladebalken-Dauer
  - Namen der anderen Tabs (kommagetrennt)
- Alle anderen Knöpfe haben keine Funktion.

## Installation auf iPad/iPhone
1. Seite in Safari öffnen (gehostete URL, z. B. GitHub Pages).
2. Teilen → „Zum Home-Bildschirm“ → „Als Web-App öffnen“ aktiv lassen.
3. Das Icon heißt „Safari“ und startet im Vollbild ohne echte Browser-Leiste.
4. **In der installierten App** über das geheime Menü das Bild wählen (Speicher der Home-Bildschirm-App ist getrennt von Safari).

Tipp: Als Bild einen Screenshot **ohne** Safari-Leiste nehmen (oben zuschneiden), sonst gibt es die Leiste doppelt.
